\section{Experiments}

This section evaluates MHILLM on three public lithium-ion battery datasets. We first describe the datasets, comparison methods, evaluation protocol, and implementation details. We then examine the overall SOH estimation accuracy, followed by component ablations and parameter-sensitivity analyses. Unless otherwise stated, SOH, MAE, and RMSE are expressed on the normalized scale from 0 to 1, while MAPE is reported as a fraction rather than a percentage.

\subsection{Datasets}

We conduct experiments on the NASA, CALCE, and Oxford battery-aging datasets. These datasets contain different cells, cycling procedures, sampling resolutions, and degradation trajectories, thereby providing complementary test conditions for SOH estimation.

\textbf{NASA.} The NASA battery dataset records repeated charge--discharge experiments under controlled operating conditions. We use the four cells adopted in our benchmark and arrange their measurements in chronological order. The discharge capacity of each cell is divided by its rated capacity to obtain the normalized SOH label.

\textbf{CALCE.} The CALCE dataset contains long-term cycling measurements collected from four lithium-ion cells. Compared with NASA, its capacity trajectories contain different degradation rates and local variations. We construct the same set of health indicators for every available cycle and normalize the measured capacity by the corresponding rated capacity.

\textbf{Oxford.} The Oxford dataset provides aging trajectories for eight pouch cells. Capacity measurements are associated with periodic characterization records rather than every intervening aging cycle. Therefore, one temporal step on Oxford denotes one available characterization record, and the task predicts the SOH associated with the next record.

For all datasets, preprocessing statistics, missing-value handling parameters, health-indicator normalization, and model parameters are fitted using training cells only. Information from validation and test cells is never used to select indicators or estimate normalization statistics.

\subsection{Baselines}

We compare MHILLM with conventional regression methods, neural sequence models, Transformer architectures, and recent pretrained time-series models.

$\bullet$ \textbf{GPR}: Gaussian process regression establishes a nonlinear probabilistic mapping from the input health indicators to SOH.

$\bullet$ \textbf{SVR}: Support vector regression estimates SOH using a kernel-based maximum-margin regressor.

$\bullet$ \textbf{GRU}: The gated recurrent unit processes the historical HI records sequentially and models cycle-to-cycle degradation dependencies.

$\bullet$ \textbf{TCN}: The temporal convolutional network uses causal dilated convolutions to capture local and multi-scale temporal patterns.

$\bullet$ \textbf{CNN--LSTM}: A convolutional front end extracts local degradation features, which are subsequently modeled by an LSTM.

$\bullet$ \textbf{Transformer}: A standard Transformer encoder learns global dependencies among the historical multivariate HI records.

$\bullet$ \textbf{BMSFormer}: BMSFormer combines local and global feature modeling for efficient battery SOH estimation. We adapt its network to the common input and evaluation protocol used in this study.

$\bullet$ \textbf{DLinear}: DLinear decomposes a sequence into slowly varying and residual components and applies linear projections to produce the prediction.

$\bullet$ \textbf{GPT4TS}: GPT4TS adapts a pretrained GPT-2 backbone to numerical time-series modeling through partial parameter fine-tuning.

All baselines receive the same leakage-free historical windows and are evaluated on identical cell-disjoint folds. Hyperparameters are selected using validation cells without referring to test labels.

\subsection{Experiment Settings}

\textbf{Evaluation metrics.} We use mean absolute error (MAE), root mean squared error (RMSE), and mean absolute percentage error (MAPE) to quantify estimation accuracy:
\begin{gather}
\operatorname{MAE}=\frac{1}{N}\sum_{n=1}^{N}\left|y_n-\hat{y}_n\right|,\\
\operatorname{RMSE}=\sqrt{\frac{1}{N}\sum_{n=1}^{N}\left(y_n-\hat{y}_n\right)^2},\\
\operatorname{MAPE}=\frac{1}{N}\sum_{n=1}^{N}
\left|\frac{y_n-\hat{y}_n}{y_n}\right|,
\end{gather}
where $y_n$ and $\hat{y}_n$ are the reference and estimated normalized SOH values, respectively. Because the factor of 100 is not applied in the last equation, a MAPE value of 0.01 corresponds to an average relative error of 1\%.

\textbf{Cell-disjoint evaluation.} The split is performed by cell identity before historical windows are generated. For NASA and CALCE, each fold uses one cell for testing, one of the remaining cells for validation, and the other two for training. Every cell serves as the test cell once. For Oxford, the same leave-one-cell-out principle is applied to its eight-cell pool, while the validation assignment is fixed for each fold. This protocol evaluates transfer to an unseen cell from the same dataset. It does not, by itself, constitute cross-dataset or cross-chemistry transfer.

For a target at time $t+1$, the input consists of the $L$ available records ending at time $t$. The window advances by one record to construct the next sample and never crosses cell boundaries. NASA and CALCE use the next available aging-cycle record as the target. Oxford uses the next characterization record because measurements for every intervening aging cycle are unavailable. All preprocessing, alignment, and downstream model fitting are repeated independently within each fold.

\textbf{Implementation details.} We adopt GPT-2 with hidden dimension $d=768$ and retain its first six Transformer blocks. The trend and fluctuation sequences share the same backbone parameters. The default model uses $L=16$ historical records, four cross-HI attention heads, multi-scale pooling kernels $\{3,5,9\}$, and LoRA rank $r=8$ with scaling coefficient $\alpha_l=16$. AdamW is used with a batch size of 32, and the learning rate is selected from $\{10^{-4},5\times10^{-4},10^{-3}\}$ using the validation set. Training stops when the validation objective does not improve for ten consecutive epochs. The autoregressive alignment checkpoint is selected by validation HI-prediction loss, whereas the downstream checkpoint is selected by validation MAE. The tokenizer, cross-HI module, regression head, positional embeddings, normalization layers, and LoRA parameters are optimized. The original attention and feed-forward projections of GPT-2 remain frozen.

For neural baselines, the reported values are aggregated over the completed random-seed runs and all test folds. GPR and SVR are treated as deterministic baselines under their fixed training configurations.

On NASA, MHILLM reduces MAE, RMSE, and MAPE by 9.52\%, 5.82\%, and 10.84\%, respectively, relative to the strongest competing result for each metric. The improvement is consistent across absolute and relative errors, indicating that the model does not gain accuracy only at a particular SOH range. On CALCE, the corresponding reductions are 4.03\%, 3.75\%, and 7.47\%. Although the margin is smaller on this dataset, MHILLM remains the only method that obtains the best value for all three measures.

The largest gains occur on Oxford. Compared with the best baseline in each column, MHILLM lowers MAE by 15.91\%, RMSE by 12.90\%, and MAPE by 26.79\%. This result is especially relevant because Oxford is evaluated at the characterization-record level and each fold tests a cell excluded from model fitting. The improvement suggests that the learned representation remains effective when the sampling interval and degradation profile differ from those of NASA and CALCE.

The conventional regressors produce comparatively large errors on NASA and CALCE. GPR and SVR map the engineered inputs to SOH but do not explicitly describe how multiple indicators evolve across a historical window. GRU, TCN, and CNN--LSTM exploit temporal structure and generally improve upon these regressors; nevertheless, their representations are learned solely from the available battery-training folds and provide limited mechanisms for separating persistent degradation from short-lived capacity recovery.

Transformer-based and decomposition-based baselines are more competitive. The standard Transformer benefits from global dependency modeling, BMSFormer combines local and global information, and DLinear provides a strong result on CALCE through a simple decomposition prior. GPT4TS attains the strongest baseline RMSE and MAPE on NASA, demonstrating the value of adapting a pretrained sequence model. Its weaker Oxford performance, however, indicates that direct LLM adaptation alone does not guarantee robust multi-indicator modeling under a different record structure.

MHILLM combines three sources of information that are absent as a whole from the baselines. First, cycle-wise decomposition separates gradual capacity fading from transient fluctuations, reducing interference from capacity regeneration. Second, cross-HI attention models the dependence among heterogeneous indicators rather than treating their concatenation as a fixed representation. Third, autoregressive HI alignment and LoRA adaptation orient the pretrained backbone toward degradation dynamics before SOH regression. The consistent reduction of all three errors supports the joint use of these designs for unseen-cell estimation.

\subsection{Ablation Studies}

We design component ablations to isolate the contribution of the main architectural and training choices. Every variant uses the same cell-disjoint folds, preprocessing procedure, training budget, and model-selection rule as the full model.

$\bullet$ \textbf{w/o Decomposition}: The original normalized HI sequence is supplied to a single branch without separating the smooth trend and fluctuation components.

$\bullet$ \textbf{Trend Only}: The fluctuation branch is removed, and SOH is estimated using only the smooth degradation component.

$\bullet$ \textbf{Fluctuation Only}: The trend branch is removed, leaving only the short-term residual component.

$\bullet$ \textbf{w/o Cross-HI Attention}: Cross-HI attention is replaced by a shared linear projection followed by direct HI aggregation.

$\bullet$ \textbf{w/o Context Token}: The degradation-context token constructed from the instance statistics is removed.

$\bullet$ \textbf{w/o AR Alignment}: The autoregressive next-HI alignment stage is skipped, and the SOH estimator is trained directly from the pretrained initialization.

$\bullet$ \textbf{w/o LoRA}: The LoRA matrices are removed while the remaining trainable modules and partial-freezing policy are retained.

Table \ref{tab:component_ablation} provides a controlled assessment of MHILLM from three complementary perspectives: degradation representation, multi-HI interaction, and pretrained-model adaptation. For degradation representation, w/o Decomposition feeds the original HI sequence directly into a single branch, and therefore tests whether explicitly separating slow capacity fading from short-lived recovery and measurement fluctuations is necessary. Trend Only retains the smoothed component and removes the fluctuation branch, whereas Fluctuation Only preserves only the residual component. For multi-HI interaction, w/o Cross-HI Attention replaces adaptive indicator interaction with direct aggregation. The w/o Context Token variant further removes the window-level mean, standard deviation, and observation statistics, thereby isolating the absolute health-level information that may be weakened by instance normalization. For pretrained-model adaptation, w/o AR Alignment bypasses next-record HI prediction and trains the network directly using SOH labels. The w/o LoRA variant freezes the original GPT-2 projections while retaining the remaining trainable modules. All variants use the same cell-disjoint folds, historical windows, optimization budget, validation rule, and random seed.

The results identify the context token as the most consistently useful component. Removing it raises MAE from 0.0249 to 0.0692 on NASA, from 0.0139 to 0.0670 on CALCE, and from 0.0092 to 0.0224 on Oxford; RMSE and MAPE deteriorate in the same manner. Cross-HI attention is also beneficial relative to the complete model, particularly on NASA, where its removal increases MAE and RMSE to 0.0299 and 0.0358, respectively. AR alignment reduces all three errors on NASA, although its effect is smaller on CALCE and Oxford. The representation variants reveal a less uniform pattern. Fluctuation Only achieves the lowest errors on NASA and Oxford, while Trend Only obtains the lowest CALCE MAE. Likewise, removing LoRA slightly improves CALCE MAPE and all three Oxford metrics, even though it degrades NASA. Thus, this single-seed study strongly supports the context token and provides partial evidence for cross-HI interaction and AR alignment, but it does not establish that dual-branch decomposition or LoRA is uniformly beneficial across datasets. Repeated-seed evaluation is required before making a broader claim about those two components.

\textbf{Backbone ablation.} We further investigate whether the performance of MHILLM arises from its battery-specific modules or depends strongly on the selected language-model backbone. To this end, GPT-2 is replaced with three representative pretrained architectures, namely GPT, BERT, and T5. The HI construction, cycle-wise decomposition, instance normalization, cross-HI attention, context-token generation, historical input length, and SOH regression objective are kept unchanged. When the hidden dimensions of different backbones are inconsistent, a trainable linear projection is used only to match the backbone input and output dimensions. Model selection continues to rely exclusively on the validation cell. This controlled replacement allows the comparison to focus on the sequential prior supplied by each pretrained architecture rather than on changes in battery features or evaluation data. GPT and GPT-2 employ causal decoder-only attention and therefore follow the chronological direction of degradation naturally. BERT uses a bidirectional encoder, allowing every historical token within the observed window to interact with the others, whereas T5 adopts an encoder--decoder formulation and introduces a different denoising pretraining objective. These distinctions may influence how the model represents long-term fading, local capacity recovery, and dependencies among distant cycles. Since the four backbones also differ substantially in parameter count and computational structure, we report trainable and total parameters together with average training time per epoch and prediction errors. Runtime is measured on the same hardware with an identical batch size and excludes one-off data preprocessing and model-loading time.

Table \ref{tab:backbone_ablation} separates predictive accuracy from computational complexity. The comparison between GPT and GPT-2 examines whether differences in causal pretraining scale and representation quality translate into more accurate degradation modeling. The BERT variant tests whether unrestricted interaction among already observed historical records benefits SOH estimation, while the T5 variant evaluates whether an encoder--decoder prior provides additional modeling capacity for the numerical sequence. MAE and RMSE should be interpreted jointly with the parameter count and time per epoch: a lower error obtained through a substantially larger or slower backbone may be less attractive for repeated training or resource-constrained battery-management applications. Conversely, a compact backbone that approaches the best accuracy may offer a more favorable deployment trade-off. The final interpretation should therefore identify whether accuracy follows architecture type, computational cost, or parameter scale, rather than treating model size alone as the explanation for any observed difference.

The history-length experiment evaluates the balance between degradation context and the number of valid windows. The depth study measures whether additional pretrained blocks supply useful abstraction or introduce unnecessary capacity for the available battery data. Varying $N_a$ tests the granularity of cross-indicator interaction, whereas the LoRA study measures the adaptation capacity required to bridge language and battery sequences. Finally, the pooling configurations determine whether a single smoothing scale is sufficient or whether multiple temporal resolutions are needed to separate gradual fading from local recovery. Parameter conclusions should be drawn from the validation-consistent trends after the corresponding results are available.
